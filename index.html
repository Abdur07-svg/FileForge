          Privacy Policy & Security Guarantee
        

        
      

      

        

          Zero-Knowledge Client-Side Architecture: Your files never leave your device. All 50 PDF, image, and archive tools run entirely in your local browser memory (RAM).
        


        
1. 100% Client-Side Privacy

        

          Unlike conventional online file converters that upload your confidential PDFs, contracts, financial statements, and personal photos to remote cloud servers, FileForge processes 100% of your data locally inside your web browser.
        


        
2. Data Collection & Handling

        
    
          
  • Zero Server Uploads: Files selected or dropped into FileForge are read directly into browser memory (ArrayBuffer, HTML5 Canvas, Blob). Zero bytes of file content are transmitted across the internet.
    • 
          
  • No Database or Cloud Storage: We do not operate any server-side database or file repository. Once you close or refresh your browser tab, all temporary memory allocations are immediately destroyed by the browser garbage collector.
    • 
          
  • Zero Tracking & No Profiling: We do not track user identities, document filenames, page counts, or file metadata.
    • 
          
  • Local Preferences Only: The only information saved locally on your device is your UI theme choice (Dark Mode or Light Mode), stored safely in your browser's local storage (fileforge_theme).
    • 
        


        
3. How You Can Verify Our Privacy Guarantee

        

          You do not need to take our word for it. You can independently verify our zero-upload guarantee at any time:
        

        
    
          
  1. Open your browser's Developer Tools by pressing F12 or right-clicking anywhere and choosing Inspect.
    2. 
          
  2. Select the Network tab and check the Fetch/XHR filter.
    3. 
          
  3. Upload, compress, or convert any file in FileForge.
    4. 
          
  4. Observe that no HTTP POST or file upload network requests occur. You can even disconnect your internet entirely after opening the site and all 50 tools will continue to function!
    5. 
        


        
4. Compliance & Regulatory Standards

        

          Because FileForge does not collect, process, or store any personal data on external servers, it is inherently compliant with the EU General Data Protection Regulation (GDPR), the California Consumer Privacy Act (CCPA), and HIPAA data confidentiality principles.
