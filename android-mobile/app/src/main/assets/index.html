About FileForge

FileForge is a browser-based file utility platform designed to make everyday file conversion, compression, editing, and file management simple and convenient.

FileForge provides tools for working with PDFs, images, ZIP files, and other supported file formats. Depending on the tool and platform, users can compress, convert, resize, merge, split, extract, preview, organize, and process files directly on their device.

Our goal is to provide a simple and practical file-processing experience without requiring users to create an account or use complicated software.

FileForge is designed around:
  • Simple and easy-to-use tools
  • Fast file processing
  • Local, browser-based processing where supported
  • No unnecessary account creation
  • No unnecessary permissions
  • Clean and user-friendly interface
  • Desktop and mobile support

Many FileForge tools process files directly inside the browser or on the device. The exact processing method may vary depending on the tool, browser, operating system, and third-party libraries used.

FileForge Mobile is the dedicated Android version of FileForge, optimized for touch devices and frequently used file-processing tools.

Users remain responsible for the files they select, process, download, share, or otherwise use with FileForge.

Always keep an original copy of important files before compression, conversion, editing, splitting, merging, or other processing.

FileForge is a file utility tool and does not guarantee that every generated file will preserve every feature, structure, metadata field, formatting element, or functionality of the original file.

Privacy Policy

Last Updated: March 2026
FileForge Mobile does not intentionally upload selected files to a FileForge server for normal local file-processing operations.

FileForge respects your privacy. This Privacy Policy explains how FileForge handles files, information, preferences, and other data when you use FileForge.

1. Files You Select

FileForge is designed so that many file-processing operations can be performed directly in your browser or on your device.

For tools that support local processing:

  • Files selected through the Android system file picker are processed directly on your device.
  • Files are not intentionally uploaded to a FileForge server for processing.
  • Temporary processing data exists only in temporary device memory (RAM) while the tool is being used.
  • Temporary data and memory allocations are released when no longer required or when leaving the tool.

2. File Storage

FileForge does not intentionally store uploaded files permanently as part of its normal local-processing workflow. Downloaded/exported files are controlled by the Android operating system and saved directly into your device's Downloads directory.

3. Personal Information & Minimal Permissions

Core FileForge tools do not require users to create an account, log in, or provide personal details (name, email, phone number, government ID, passwords, or payment details). FileForge requests minimal permissions and uses Android's native Storage Access Framework picker.

4. Local Preferences

FileForge may store basic UI preferences locally in device storage, such as:

  • Dark Mode preference
  • Haptic Feedback preference
  • Confirm Before Exit preference

These preferences are completely separate from processed files.

5. No File Persistence

FileForge does not use persistent local storage (localStorage, IndexedDB, or cache) to save user documents, uploaded files, generated PDFs, images, passwords, or extracted contents.

6. Cookies, Analytics and Tracking

The core FileForge mobile application does not include third-party tracking cookies, behavioral analytics, or advertising telemetry SDKs.

7. Third-Party Open Source Libraries

FileForge uses verified open-source libraries (PDF.js, pdf-lib, JSZip) bundled locally within the APK package.

8. External Links & Android Limitations

When following external links, the respective external privacy policies apply. While local processing minimizes file transfers, users should avoid processing sensitive documents on insecure devices.

9. Contact

For privacy inquiries, contact: support@fileforge.app
