About FileForge

FileForge Mobile is a dedicated, lightweight Android utility application providing 15 essential PDF, Image, and ZIP archive tools.

⚡ Local & Private by Design

Unlike traditional file tools that upload your sensitive documents to remote servers, FileForge Mobile executes 100% of processing directly within your device's memory. Your bank statements, personal photos, and contracts never leave your phone.

📱 15 Essential Tools

Designed from the ground up for portrait-first phone screens, touch interactions, and Android gesture navigation. Includes PDF compression, multi-image to PDF with mixed orientations, PDF merging, splitting, lossless format conversion, and ZIP archiving.

🛡️ Zero Accounts & Zero Trackers

No login, no subscriptions, no ads, and no external telemetry. FileForge is completely free and works completely offline once packaged into the APK.

Version: 1.0.0 • Architecture: Universal APK • Target SDK: Android 14+

Privacy Policy

Summary: Supported files are processed locally on your device and are not uploaded to a FileForge server for processing.

1. File Processing & Temporary Memory

When you select a file (PDF, Image, or Archive), it is loaded solely into temporary device memory (RAM) and processed using local client-side engines. Once you navigate away from a tool, all temporary memory references, canvases, and object URLs are immediately revoked.

2. Zero Data Collection

FileForge Mobile does not collect, transmit, store, or sell any personal data, file metadata, IP addresses, or device identifiers. There are no tracking scripts, analytics SDKs, or background telemetry.

3. Local Preferences Storage

The application uses local device storage (localStorage) exclusively to remember harmless UI preferences: your Theme (Dark/Light), Haptic Feedback toggle, and Exit Confirmation toggle. No user files or document contents are ever stored in persistent storage.

4. Permissions

FileForge Mobile does not request broad file storage permissions. It uses Android's native system file picker to open only the specific files you choose to process.
